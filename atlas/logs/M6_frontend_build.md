## Summary

Built a working Vite + React + TS frontend that:
1. Loads lottery history from a static JSON snapshot
2. Runs Bayesian L2 (symbol-aggregated) predictor
3. Renders Top-N ranked probabilities with visual heatmap
4. Shows coverage analysis across 生肖/五行/波色/单双
5. Includes an "Expected loss" calculator (the sobering widget)
6. Backtest visualizer (will populate once ≥2 periods loaded)
7. Prominent, non-dismissable disclaimer banner

### Known limitations / next steps

1. **Only 1 period ingested** — backtest chart shows "0 periods". Need M2.5 batch fetch to get ≥2 periods for backtest to populate.
2. **No historical symbol tables** — currently using 2026 only. If user wants 2020-2025 backfill, that's a separate M2 sub-task.
3. **Single lottery type** — only 澳门 (lt=2). 香港 could be added with a switch.
4. **Predictor needs more data** — currently the L2 model has only 1 sample period (7 draws), so signal is essentially zero beyond artifact-level. With 100+ periods, the Bayesian model would actually differentiate.
5. **No real-time refresh** — page polls snapshot.json every 60s but doesn't auto-pull from the API. Cron would need to be added.

### Two bugs found during testing (fixed)

1. **ExpectedLoss showed +1818% ROI** — was using `(n/49) × payout - cost` which doesn't account for the fact that payouts < 49× always yield negative EV when n ≤ 49. Fixed by using proper EV formula `(n/49) × (payout - cost) - (1 - n/49) × cost`.
2. **CoverageAnalyzer showed 单 0/50, 双 0/48** — caused by hardcoding 25/24 then ALSO incrementing in the loop. Fixed by initializing to 0 and letting the loop count.
